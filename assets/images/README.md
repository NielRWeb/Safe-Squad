# assets/images

All artwork in SAFE SQUAD is original inline SVG generated in code
(`src/art/characters.ts` and `src/art/scenes.ts`), so no image files are required.

Drop your own PNG/SVG/WebP files here if you want to replace or extend the art, then
import them where they are needed, e.g.:

```ts
import bannerUrl from '../../assets/images/banner.png';
```

Keep images small (< 200 KB) so the game stays fast on student phones.
